# Сборка LunLandQuests через GitHub Actions

1. Создай новый репозиторий на GitHub, например `LunLandQuests`.
2. Загрузи в него папку `LunLandQuests` и папку `.github` из этого архива.
3. Открой вкладку **Actions**.
4. Выбери **Build LunLandQuests**.
5. Нажми **Run workflow**.
6. После завершения открой успешный запуск и скачай artifact **LunLandQuests-1.0.0**.
7. Внутри будет готовый `.jar` для папки `plugins`.
